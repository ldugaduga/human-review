# The Human Review

Static marketing site: `about.html` and `how-it-works.html`, styled with Tailwind
CSS (CDN build) and the Onest Google Font. No build step, no framework, no
package manager.

## Commands

- Preview: open `about.html` or `how-it-works.html` directly in a browser, or
  serve the folder locally, e.g. `python3 -m http.server 4173`
- Build: none (plain HTML/CSS/JS)
- Lint / test: none configured yet

## Structure

- `about.html`, `how-it-works.html` - pages
- `assets/css/` - shared stylesheet (`main.css`)
- `assets/img/` - images, icons, and per-page media (`assets/img/how-it-works/`,
  `assets/img/teams/`)
